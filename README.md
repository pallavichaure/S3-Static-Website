# 🌐 AWS S3 Static Website Hosting Project

## 📌 Project Overview

This project is a static travel website hosted using **Amazon Simple Storage Service (AWS S3)**.

The website contains multiple pages including destination details, travel packages, booking page, contact page, and guide information.

The project demonstrates how to deploy and host a static website using AWS cloud services.

# ☁️ AWS S3 Deployment Steps

## 1. Create S3 Bucket

- Created an AWS S3 bucket
- Enabled static website hosting
- Configured bucket permissions


## 2. Upload Website Files

Uploaded:

- HTML files
- CSS files
- JavaScript files
- Images


## 3. Configure Website Hosting

Configured:

- Index document
- Error document
- Bucket policy


## 4. Access Website

Website is accessed using AWS S3 static website endpoint.
